Write one line of weather, 140 characters at most, for a city that does not exist. A judge playing a bored commuter picks the line that makes them smile.

## Run it

```sh
python3 main.py
```

The program writes a single one-line forecast for the invented city of Umbrella Falls — where the rain falls upwards — to `/output/entry.txt`.
